# LongShot

Windows 本地长截图切分工具。把较长的 PNG/JPEG 图片切成更方便阅读的图片，尽量在空白位置分段并保留内容衔接。

## 下载与使用

从本项目的 Releases（版本发布页）下载 `LongShot-1.0.0-Windows-x64.zip`。

1. **完整解压**到有写入权限的本机文件夹。
2. 双击 `LongShot.exe`，保留同目录的 `_internal` 文件夹。
3. 选择或拖入 PNG/JPEG 图片，确认清单后开始处理。
4. 通过“查看切图”打开结果。输出保存在程序旁的“输出”文件夹，按月份和批次整理。

这是 Windows 64 位免安装版，无需另外安装 Python。请先解压，再运行程序。

## 功能与边界

- 支持 PNG/JPEG，默认每批最多100张；单张不超过25 MiB和6000万像素。
- 原文件只读，另存原图副本和切图；支持取消当前批次。
- 以内容完整、清楚阅读和尽量少切为原则，张数随图片变化。
- 无需切分且无需方向或透明底转换时保留原字节；其他结果使用 JPEG。
- 不包含文字识别或去广告功能；个别版式可能没有理想切口，切图合集也可能略大于原图。

详细操作、取消与清理行为、设置方法见压缩包内的 `使用说明.txt`。

## 本地处理与设置

图片和处理结果保存在本机。

`配置/设置.json` 中的“每批最多图片数”默认为100；修改后重启生效，提高数字不代表更大负载已经验证。

## 下载校验与兼容性
